# shell-emulator

## Общее описание

Эмулятор оболочки UNIX-подобной ОС с консольным интерфейсом (CLI).
Работает по схеме REPL: чтение команды, выполнение, вывод результата.
Текущий этап: **2 — конфигурация** (ls и cd пока заглушки).

## Описание функций и настроек

Параметры командной строки:

- `--vfs ПУТЬ` — путь к физическому расположению VFS. Имя файла
  показывается в приглашении к вводу (`demo.json:$ `).
- `--script ПУТЬ` — путь к стартовому скрипту.

При запуске выводятся отладочные строки `[debug]` со всеми параметрами.

Стартовый скрипт — текстовый файл, одна команда на строку. Пустые
строки и строки, начинающиеся с `#`, пропускаются. На экране виден
и ввод, и вывод. Ошибочные строки пропускаются, об ошибке сообщается
в stderr (`ошибка в строке N скрипта: ...`). После скрипта эмулятор
переходит в интерактивный режим, если скрипт не завершился командой
`exit`. Если файл скрипта не найден, выводится сообщение об ошибке.

Команды:

- `ls [аргументы]` — заглушка, печатает имя и аргументы.
- `cd [путь]` — заглушка, не более одного аргумента.
- `exit` — завершает работу.

Парсер поддерживает аргументы в кавычках: `ls "my folder"`.

## Сборка и запуск тестов

Нужен Python 3.9 или новее. Сборка не требуется.

    ./run.sh                              # эмулятор
    ./run.sh --vfs vfs/demo.json          # с параметром VFS
    ./run.sh --script scripts/data/good.emu
    ./run.sh test                         # автотесты

Скрипты для проверки параметров запуска лежат в `scripts/`:

    sh scripts/test_no_params.sh
    sh scripts/test_vfs_param.sh
    sh scripts/test_script_param.sh
    sh scripts/test_all_params.sh
    sh scripts/test_script_errors.sh

## Примеры использования

    $ ./run.sh --vfs vfs/demo.json --script scripts/data/good.emu
    [debug] параметры запуска:
    [debug]   vfs    = vfs/demo.json
    [debug]   script = scripts/data/good.emu
    demo.json:$ ls
    ls: аргументы = []
    demo.json:$ ls "my folder" file.txt
    ls: аргументы = ['my folder', 'file.txt']
    demo.json:$ cd docs
    cd: аргументы = ['docs']
    demo.json:$ exit
