# shell-emulator

## Общее описание

Эмулятор оболочки UNIX-подобной ОС с консольным интерфейсом (CLI).
Работает по схеме REPL: чтение команды, выполнение, вывод результата.
Текущий этап: **1 — REPL** (команды ls и cd пока заглушки).

## Описание функций и настроек

- Приглашение к вводу содержит имя VFS (`myvfs:$ `).
- Парсер поддерживает аргументы в кавычках: `ls "my folder"`.
- `ls [аргументы]` — заглушка, печатает имя и аргументы.
- `cd [путь]` — заглушка, печатает имя и аргументы (не более одного).
- `exit` — завершает работу.
- Ошибки (неизвестная команда, неверные аргументы, незакрытая
  кавычка) выводятся в stderr, эмулятор продолжает работу.

## Сборка и запуск тестов

Нужен Python 3.9 или новее. Сборка не требуется.

    ./run.sh          # запуск эмулятора
    ./run.sh test     # запуск тестов

## Примеры использования

    myvfs:$ ls
    ls: аргументы = []
    myvfs:$ ls "my folder" file.txt
    ls: аргументы = ['my folder', 'file.txt']
    myvfs:$ cd a b
    cd: слишком много аргументов
    myvfs:$ foo
    foo: команда не найдена
    myvfs:$ ls "oops
    ошибка разбора: No closing quotation
    myvfs:$ exit
