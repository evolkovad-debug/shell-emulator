# shell-emulator

## Общее описание

Эмулятор оболочки UNIX-подобной ОС с консольным интерфейсом (CLI).
Работает по схеме REPL: чтение команды, выполнение, вывод результата.
Текущий этап: **4 — основные команды** (ls, cd, find, cal, whoami).

## Описание функций и настроек

Параметры командной строки:

- `--vfs ПУТЬ` — JSON-файл виртуальной файловой системы (VFS).
  Имя файла и текущий каталог показываются в приглашении
  к вводу: `deep.json:/home$ `.
- `--script ПУТЬ` — путь к стартовому скрипту.

При запуске выводятся отладочные строки `[debug]` со всеми параметрами.

### Стартовый скрипт

Текстовый файл, одна команда на строку. Пустые строки и строки,
начинающиеся с `#`, пропускаются. На экране виден и ввод, и вывод.
Ошибочные строки пропускаются, об ошибке сообщается в stderr
(`ошибка в строке N скрипта: ...`). После скрипта эмулятор переходит
в интерактивный режим, если скрипт не завершился командой `exit`.

### VFS

VFS загружается из JSON-файла целиком в память и на диске не
изменяется. Узел — это объект с полем `type`:

- `{"type": "dir", "children": {"имя": узел, ...}}` — каталог;
- `{"type": "file", "content": "текст"}` — текстовый файл;
- `{"type": "file", "encoding": "base64", "content": "..."}` —
  двоичный файл.

Корень должен быть каталогом. При ошибке загрузки (файл не найден,
неверный JSON, неверная структура или base64) печатается сообщение
`ошибка загрузки VFS: ...`, код выхода 1.

### Команды

- `ls [-l] [путь...]` — содержимое каталогов (`-l`: тип и размер).
- `cd [путь]` — сменить каталог; без пути — корень; поддержаны
  `.`, `..`, абсолютные и относительные пути.
- `find [путь] [-name шаблон] [-type f|d]` — поиск по дереву VFS.
- `cal [[месяц] год]` — календарь месяца или года.
- `whoami` — имя текущего пользователя.
- `vfs-info` — служебная команда: сводка по загруженной VFS.
- `exit` — завершает работу.

Парсер поддерживает аргументы в кавычках: `ls "my folder"`.

## Сборка и запуск тестов

Нужен Python 3.9 или новее. Сборка не требуется.

    ./run.sh --vfs vfs/deep.json          # эмулятор с VFS
    ./run.sh --script scripts/data/stage4_all.emu
    ./run.sh test                         # автотесты

Скрипты проверки лежат в `scripts/` (запуск: `sh scripts/имя.sh`):

- `test_no_params`, `test_vfs_param`, `test_script_param`,
  `test_all_params`, `test_script_errors` — параметры (этап 2);
- `test_vfs_minimal`, `test_vfs_several`, `test_vfs_deep` — разные
  VFS из папки `vfs/`; `test_vfs_errors` — ошибки загрузки VFS;
- `test_stage4_all` — стартовый скрипт со всеми командами.

## Примеры использования

    $ ./run.sh --vfs vfs/deep.json --script scripts/data/info.emu
    [debug] параметры запуска:
    [debug]   vfs    = vfs/deep.json
    [debug]   script = scripts/data/info.emu
    deep.json:/$ vfs-info
    VFS deep.json: каталогов 4, файлов 4, байт 53, уровней 4
    deep.json:/$ cd home
    deep.json:/home$ ls
    user
    deep.json:/home$ exit
